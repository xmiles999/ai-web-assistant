# 隐私说明

本扩展没有自有后端、统计脚本或云端账户。

默认不收集整页内容、Cookie、表单、密码、浏览历史或网页存储。默认只在用户触发动作时读取选中文字；标题和 URL 默认不发送。用户主动选择的 AI 服务会接收提交的文本和 Prompt，具体保留和训练规则由该服务商决定。

历史记录默认关闭。开启后，选中文字和回答保存在本地 IndexedDB，可在设置或 Side Panel 中导出和删除。导出不包含 API Key。

扩展安装时请求所有普通 HTTP/HTTPS 网站权限，以便选中文字后默认显示工具栏。Content Script 不会因此读取整页正文，也不会自动把网页内容发送给 AI；只有用户点击 AI 动作后，选中文字才会发往当前配置的服务。用户可以在 Chrome 扩展详情中限制网站访问权限。Chrome 内部页面和商店页不支持注入。

新服务默认“记住 API Key”，在本机扩展存储中保存未做口令加密的 Key，浏览器重启后无需再次输入，不使用 Chrome 同步。仅建议在自己的设备使用；删除服务配置可移除 Key。用户可改为仅会话保存或口令加密保存；旧配置不自动转换。
