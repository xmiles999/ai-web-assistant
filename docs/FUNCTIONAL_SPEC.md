# 功能说明

版本：0.2.1

状态：首期本地插件实现

## 目标与范围

用户安装扩展时授权普通 HTTP/HTTPS 网站访问。安装完成后，在普通网页选择文字会自动显示选区旁工具栏；右键菜单仍可使用。请求由用户配置的 AI 服务处理，插件不提供云端代理。

范围内：全站选区工具栏、内联结果弹窗、右键菜单、Side Panel、OpenAI 兼容与 Azure 配置、自定义 Prompt、可选本地历史、本机记住、会话或口令加密 API Key。

范围外：账号、云同步、Agent、RAG、MCP、官网和商业化。

## 核心流程

1. 用户在 HTTP/HTTPS 页面选择非空文本。
2. Content Script 在普通 HTTP/HTTPS 页面显示悬浮工具栏；安装、更新或新增站点权限时，Service Worker 会对已打开的可访问标签页执行幂等补注入。
3. 工具栏动作建立受验证的 PendingTask，并在选区附近打开内联结果弹窗。
4. “询问 AI”先在弹窗收集问题，其他动作直接启动流式任务。
5. Service Worker 按保存方式读取密钥和配置，发送 Chat Completions SSE 请求。
6. 网页弹窗增量显示纯文本结果，支持停止、复制、重试和打开设置。
7. 右键菜单和扩展入口继续打开 Side Panel，提供长内容和历史工作区。

## 默认动作

询问 AI、翻译、总结、解释、润色、代码分析。所有动作都把选区视为不可信数据；标题和 URL 默认不发送。

## 失败与恢复

空选区、超长输入、未配置服务、未解锁密钥、权限拒绝、401/403/404、429、5xx、超时、网络错误和受限页面都必须展示原因与下一步。请求取消后停止追加文本，不自动重复已产生内容。

## 验收

验收命令和边界见 README、技术开发说明及测试文件。历史默认关闭；只有用户显式开启后才写入 IndexedDB。

## 密钥使用体验

- 新配置默认“记住 API Key”，一次填写后可跨浏览器重启使用，无需解锁口令；本机存储未做口令加密，界面明确提示风险。
- 旧配置不自动转换。用户编辑并保存为“记住 API Key”时，沿用已有可用 Key；加密 Key 尚未解锁时需先解锁或重新输入。
- 编辑时 Key 留空表示不更换，切换回会话或加密模式会移除旧的明文持久副本。删除服务配置会移除对应密钥。
- 不保证 Key 永久有效：服务商撤销/失效、清除扩展数据、卸载扩展或换用其他浏览器配置后仍需重新配置。
