# 功能说明

版本：0.1.0

状态：首期本地插件实现

## 目标与范围

用户在普通网页选择文字后，可以使用右键菜单；在主动授权的网站上，可以使用选区旁悬浮工具栏。请求由用户配置的 AI 服务处理，插件不提供云端代理。

范围内：选区、右键菜单、站点授权、Side Panel、OpenAI 兼容与 Azure 配置、自定义 Prompt、可选本地历史、会话或口令加密 API Key。

范围外：账号、云同步、Agent、RAG、MCP、官网和商业化。

## 核心流程

1. 用户在 HTTP/HTTPS 页面选择非空文本。
2. 右键菜单可直接调用动作；悬浮工具栏只在站点权限已授予时出现。
3. 扩展建立 PendingTask，打开 Side Panel。
4. Side Panel 对“询问 AI”先收集问题，其他动作直接启动流式任务。
5. Service Worker 读取会话密钥和配置，发送 Chat Completions SSE 请求。
6. Side Panel 增量显示内容，用户可以停止、复制或重试。

## 默认动作

询问 AI、翻译、总结、解释、润色、代码分析。所有动作都把选区视为不可信数据；标题和 URL 默认不发送。

## 失败与恢复

空选区、超长输入、未配置服务、未解锁密钥、权限拒绝、401/403/404、429、5xx、超时、网络错误和受限页面都必须展示原因与下一步。请求取消后停止追加文本，不自动重复已产生内容。

## 验收

验收命令和边界见 README、技术开发说明及测试文件。历史默认关闭；只有用户显式开启后才写入 IndexedDB。
